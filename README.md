# Календарь событийного маркетинга для фермеров

Сервис помогает фермеру выбрать товар для продвижения под праздник, сезонность, локальное событие или маркетплейс-тренд. Календарь строится по реальному ассортименту `farmers_sku`: учитывает категорию, остаток, базовые продажи, сезонный коэффициент, скидку, маржинальность и прогноз ROI.

## Что реализовано

- календарь на месяц или квартал с фильтром по категории и выбором конкретного фермера;
- подбор SKU под событие с объяснением: почему товар релевантен, какой рост спроса ожидается и на чём основан коэффициент;
- расчёт прогноза: базовые заказы, сезонный спрос, ожидаемые заказы, выручка, валовая прибыль, затраты, ROI;
- редактируемые фермером промокод и скидка в карточке события, с сохранением в БД и локальным пересчётом прогноза в интерфейсе;
- подсказка оптимальной скидки, оценка силы события, риск по остаткам и рекомендуемый сегмент покупателей;
- комплект товаров к акции, календарь подготовки и варианты текста для push, соцсетей и карточки товара;
- план-факт после акции с сохранением фактических заказов/выручки и журналом изменений;
- экспорт плана акций в CSV;
- отдельная панель планирования: автоприоритеты месяца, калькулятор акций, рейтинг SKU и сезонная карта года;
- действия для витрины, соцсетей, email, push и других каналов;
- админка событий: даты, тип, теги, каналы, коэффициенты по категориям и источники;
- onboarding для новичка и документы с исследованием сезонности в `docs/`.

## Как запускать

```bash
docker compose up --build
```

После запуска открыть:

```text
http://localhost:9999/example-application/
```

PostgreSQL поднимается в `docker-compose.yml`, схема и данные загружаются Liquibase-миграциями из `src/main/resources/db/changelog`.

## Соответствие критериям

- Релевантность: события и акции привязаны к фермерским категориям, праздникам, сезонности, локальным событиям и трендам.
- Полнота: есть пользовательский календарь, прогноз, действия, выбор фермера, фильтры и админское управление событиями.
- UX: основной сценарий доступен с первого экрана, есть подсказки, краткие CTA и сохранение действий фермера.
- Бизнес-ценность: ROI и заказы считаются по экономике конкретного SKU, а не по общей статике.
- Качество решений: коэффициенты вынесены в данные, у каждого правила есть обоснование и источник.
- Дополнительный функционал: onboarding, админка, редактирование скидки/промокода, план-факт, история, экспорт, квартальный режим.
