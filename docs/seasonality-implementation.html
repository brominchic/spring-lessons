Перенос сезонных данных в календарь продаж

Актуализация: 10 мая 2026. Документ фиксирует, что интернет-исследование перенесено в код, БД и карточки событий.

Бизнес-ценность: карточка события теперь показывает гипотезу роста продаж через связку событие → категория товара → коэффициент → ожидаемые заказы → ROI → источник. Это дает демонстрацию роста продаж, прогноз по типам событий и примеры для категорий товаров.

Что добавлено в продукт

  • Новая таблица event_category_boosts: хранит тег категории, множитель роста, текст обоснования и источник.
  • 16 дополнительных событий в event_templates: Масленица, Пасха, пикники, летняя корзина, Медовый Спас, 11.11, Черная пятница, новогодний предзаказ.
  • API календаря дополнился полями baselineOrders, expectedOrders, upliftPercent, roiPercent, evidence.
  • Интерфейс показывает базовые заказы без события, ожидаемый прирост, ROI и ссылочное обоснование в блоке “Прогноз”.
